# App Menu

Bar widget that shows the focused application's name in bold, like the macOS menu bar.

Part of the [Liquid Glass theme for Omarchy](https://github.com/danluan/omarchy-liquid-glass-theme), but it can be used on its own.

## Install

```bash
omarchy plugin add https://github.com/danluan/app-menu-plugin.git
omarchy plugin enable danluan.app-menu --section left
```

Plugins run as unsandboxed code inside omarchy-shell: review the code before enabling it.
